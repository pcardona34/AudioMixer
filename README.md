# AudioMixer

This is a simplified fork of `VolumeControl`.

> [!CAUTION]
> The simplified code is tied to GNU/Linux operating system with only ALSA and PCM use in mind. 
> If you do not have a RPI machine, you should better consider using `AudioMixer` provided by nu-gap among [gnustep-recommended-apps](../../../gnustep-recommended-apps).

## How to install

1. Run [agnostep-apps-manager](../../../agnostep-apps-manager)
2. Select the category: *agnostep-applications*
3. Select the application: *AudioMixer*
4. Read info.
5. Confirm the installation.
